# FINTEL AI Data Access Policy

FINTEL AI receives only server-selected, typed research context. It does not receive arbitrary database credentials or arbitrary SQL execution capability.

Market observations retain source, timestamp and quality metadata where stored by the market-data layer. Portfolio context is protected by the existing authenticated procedures and is never implicitly selected by research.

The AI must distinguish factual FINTEL data from AI interpretation and must not invent unavailable financial observations or citations.
